# JotFlow 0.3.0

Drafted issues are now much fuller, and they follow the style of the repo they're filed in.

## What changes

- **The repo's own style (#249).** Before proposing, the agent reads the target repo's ten most recent issues and matches their title format, such as `feat(reports): …`, and their section headings. It copies only the form. Those issues are treated as untrusted, so their text, links, mentions and labels never carry over.
- **A structured default.** When a repo has no shared style, an issue has a Problem, a Proposal, a Suggested approach, an Acceptance checklist and Context.
- **The agent's own plan.** Even a one-line post becomes a useful issue. The agent breaks the work into steps under **Suggested approach**, which opens with "Drafted by the agent from the discussion; adjust before starting", and adds its own completion criteria to the Acceptance checklist.
- **No made-up facts.** The plan is written in words, with no commands, install steps, new dependencies or links unless the thread gave them. The agent never states current behaviour, numbers, file paths or decisions nobody gave. Points from related issues go under Context with their source, and open questions are listed rather than guessed.

Read the Suggested approach on each card before approving. Approval remains the defence for what reaches GitHub.

## Upgrade

Take a backup first, as the [deployment guide](https://github.com/Jnkman787/jotflow/blob/v0.3.0/docs/deployment.md#upgrading-and-rolling-back) shows. Nothing but the images changed since 0.2.0, so either way works:

```sh
uvx jotflow@0.3.0 init
docker compose up -d
```

Or set `JOTFLOW_IMAGE_REF` and `JOTFLOW_AGENT_IMAGE_REF` in `.env` to the `0.3.0` images, then run `docker compose up -d`. If your `.env` sets them, setup alone leaves you on the old images, so change both.

Coming from 0.1.x? Read the [0.1.1](https://github.com/Jnkman787/jotflow/blob/v0.3.0/docs/releases/v0.1.1.md#upgrade) and [0.2.0](https://github.com/Jnkman787/jotflow/blob/v0.3.0/docs/releases/v0.2.0.md#upgrade) notes as well.
